## ⚠ 확인받을 것
1. **표 3열 주차 번호가 시안끼리 다르다.**
   데스크탑 시안 = 10·11·12·13 / 모바일 시안 = 11·12·13·14.
   모바일은 BONUS 행에도 번호를 매겨(5·10·15) 1~15 가 이어지므로 모바일 쪽이 앞뒤가 맞는다.
   → **모바일 기준(11~14)으로 통일**했다. 데스크탑 시안대로 되돌릴지 확인 필요.
2. 데스크탑 시안에 **5주차가 없다** (1~4, 6~9, 11~14 + BONUS 3개 = 15칸).
   모바일은 BONUS 가 5·10·15 라 빈 번호가 없다. 데스크탑도 BONUS 에 번호를 넣을지.
3. 「기본적인 커리큘럼이며…」 안내문이 시안에서 **가운데가 아니라 오른쪽으로 172px 치우쳐**
   있다(x908, 중앙이면 x732). 일단 시안 그대로 뒀다.
4. 하단 주석 문구가 시안끼리 다르다.
   데스크탑 «주말에 진행됩니다. (날짜 사전 공지)» / 모바일 «주말(일요일)에 진행됩니다. 날짜는 사전 공지됩니다.»
   → 데스크탑 문구로 통일해 뒀다.
5. 피그마 텍스트에 오타 «놓치지 **말하야**» → «말아야» 로 고쳐서 넣었다.
6. TLAB 믹스커피는 유료 폰트이고 fsType=4(임베딩 금지)라 웹폰트로 못 싣는다.
   제목류는 아웃라인 SVG + `.sr-only`/`alt` 로 갈 수밖에 없다. 나머지는 전부 실제 텍스트다.
   폰트를 웹용으로 구매하면 `<img>` 를 텍스트로 바꾸기만 하면 된다.
7. 캐릭터 3형제(passes.png)는 그림 안에 「1개월/수강권/맛보기용 클래스」 글자가 구워져 있다.
