### 범위 지정에서 한 번 크게 틀렸다

처음엔 정규식으로 `}` 뒤에서 잘라 선택자에 접두사를 붙였는데,
**미디어쿼리 안쪽 첫 규칙이 범위를 못 받았다.** `.grid{grid-template-columns:repeat(2,1fr)}`
가 그대로 전역에 남아 다른 페이지 격자를 건드릴 수 있었다.
또 `/* GRID */` 같은 주석이 선택자에 섞여 들어갔다.

→ **주석을 먼저 지우고, `{}` 짝을 문자 단위로 세는 파서**로 다시 짰다. 지금은 누락 0건.

## 추가 수정 (2026-08-02)

### 네비게이션바가 후기 페이지에서만 달라 보이던 문제
원본의 `header{}` / `footer{}` 규칙을 `body.rv header{}` 로만 묶었더니
**사이트 공통 헤더도 결국 `<header>` 요소라 그대로 걸렸다.** `:root` 변수도 전역에 풀려 있었다.

→ `:root` 를 `body.rv` 로 가두고, 나머지 91개 규칙을 **`body.rv main ...`** 로 한 단계 더 좁혔다.
이미 DOM 에서 지운 원본 헤더/푸터 전용 규칙은 삭제.

**교훈**: 남의 페이지 CSS 를 통째로 들여올 때 `body.클래스` 하나로는 부족하다.
요소 선택자(`header`/`footer`/`nav`)가 공통 레이아웃까지 잡으므로 **컨테이너(`main`)까지 물릴 것.**
