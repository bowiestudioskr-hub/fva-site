## 1. 왜 만드는가

지금 퍼블(publ)로 만든 사이트는 **검색에 전혀 안 잡힌다.** 원인은 두 가지다.

**(1) 서버가 빈 껍데기만 내보낸다.** 구글봇으로 위장해 모든 페이지를 받아본 결과:

| 페이지 | 본문 텍스트 | `<title>` |
|---|---|---|
| 홈 | 86자 | FVA ACADEMY |
| 커리큘럼 | 116자 | FVA ACADEMY |
| 강의 소개 | 86자 | FVA ACADEMY |
| 피바뉴스 게시글 | 86자 | FVA ACADEMY |
| 자유게시판 글 | 86자 | FVA ACADEMY |

sitemap에 100개 넘는 URL이 등록돼 있지만 검색엔진 눈에는 **전부 동일한 빈 페이지**다. 페이지별 제목도 설명도 없다.

**(2) 글자가 이미지에 구워져 있다.** 홈은 13,081px 길이에 실제 텍스트가 391자뿐이고, 커리큘럼은 3,724px에 55자다. 감독 이력도 수강권 가격도 전부 JPG/PNG 안의 그림이다.

퍼블의 커스텀 코드(CSS/JS)로 우회하는 방법은 검토했으나 기각했다. 자바스크립트는 Business 플랜 이상이고, 퍼블은 React로 화면을 계속 다시 그리기 때문에 **바깥에서 넣은 글자가 지워진다.** 계속 감시하며 재삽입하는 방식은 퍼블이 업데이트할 때마다 깨진다.

## 2. 구조 — 둘로 나눈다

전부 새로 만들지 않는다. 결제·회원·강의실·게시판은 퍼블에서 이미 잘 돌아가고, 그걸 다시 만드는 게 전체 작업량의 대부분이다. 게다가 만들고 나면 결제 대사·환불·개인정보 보호·장애 대응이 전부 이쪽 책임이 된다.

**검색이 필요한 부분만 직접 만든다.**

```
fva.co.kr           ← 이번에 만드는 공식 홈페이지 (검색 대상)
  메인 / 커리큘럼 / 온라인강의 소개 / 오프라인강의 소개 / 피바뉴스
        │
        │  「수강 신청」 「로그인」
        ▼
class.fva.co.kr     ← 퍼블 (그대로 유지, 검색 대상 아님)
  로그인·회원 / 온라인강의 결제 / 내 강의실 / 영상 시청
  게시판 3종 (자유·구인구직·공모전) / 관리자
```

`class.fva.co.kr`은 새 도메인이 아니라 이미 보유한 `fva.co.kr`의 하위 주소다. 추가 비용 없음.

**한 도메인으로 합치는 방식(리버스 프록시)은 기각.** 퍼블은 외부 서비스라 로그인 쿠키·결제 콜백·소셜 로그인 리다이렉트가 모두 퍼블 주소 기준으로 동작한다. 중간에서 갈아끼우면 결제가 깨질 수 있다.

**감수하는 것**
- 관리 화면이 둘로 나뉜다 (홈페이지 문구 / 강의·회원)
- 결제 단계에서 주소가 바뀌는 게 보인다
- 게시판 글은 계속 검색 대상 밖 (필요해지면 나중에 이관)
- 퍼블 요금은 계속 나간다

## 3. 만들 페이지

| 페이지 | 디자인 기준 | 비고 |
|---|---|---|
| 메인 | **피그마 실측값** (`3398:146`, 1920×24235) | 가장 정확. 전체 분량의 절반 이상 |
| 커리큘럼 | 캡처 (3,724px) | |

- 메인: **픽셀 단위 일치**
- 그 외 + 모바일 전체: **눈으로 구분 안 되는 수준**

## 4. 핵심 원칙 — 글자를 이미지 위에 얹지 않는다

"룩 100% + 텍스트 검색"을 동시에 만족시키는 방법. 2026-07-29 실측 검증 완료.

- **평면 그래픽은 CSS로 그린다.** 초록 카드·띠 배너는 이미지를 안 쓴다. 카드가 글자를 담는 그릇이 되어, 글자가 길어지면 카드가 같이 늘어난다. **겹침이 구조적으로 불가능해진다.**
- **사진만 이미지로 남긴다.** 그리고 그 위에 글자를 얹지 않는다.
- **회전 요소는 `overflow-x: clip`으로 감싼다.** 회전한 요소는 시각적 박스가 레이아웃 박스보다 커서 가로 스크롤을 만든다. 테스트에서 14개 폭 중 11개가 이걸로 걸렸다.

### 검증 결과 (DIRECTOR'S PROFILE 섹션, 320~1920px 14개 폭)

| 검사 | 결과 |
|---|---|
| 글자가 초록 영역 밖으로 넘침 | 0px (전 구간) |
| 리스트가 두 줄로 접힘 | 0개 (원본처럼 전부 한 줄) |
| 가로 스크롤 | 0px |
| 1920px에서 리스트 폰트 | 37.99px (피그마 38px와 일치) |

프로토타입: `_퍼블_원본백업_20260726/proto/director.html`

**제목 이미지 처리**
- PNG가 아니라 **SVG**로 내보낸다 — 어떤 화면 크기에서도 안 깨지고 용량도 작다
- `<h2><img alt="수상한 아카데미가 있다?"></h2>` 형태 → 검색엔진이 제목 텍스트로 읽는다. 표준 방식이라 불이익 없음
- 나중에 웹폰트 구매 시 이미지를 텍스트로 교체만 하면 됨

## 6. 수강생 작품 섹션

유튜브·인스타를 **별도 카테고리로 나열하지 않는다.** 「수강생 작품」 안에서 각 작품이 바로 재생된다.

작품 카드 한 장의 구성:

```
[스틸 2장 또는 폰 목업 — 클릭하면 영상 재생]
┌──────────────────────────────────┐
│  김밥 프랜차이즈 숏폼 영상 공모전 대상 수상   │  ← 초록 배너 (CSS)
│         BRAND - 얌샘김밥            │
└──────────────────────────────────┘
* FVA 9기 [방OO, 김OO, 송OO …] 수강생 작품
```

수상 내역·작품명·브랜드·기수·참여 수강생이 **전부 진짜 텍스트**가 된다. 「2024 BCU 콘텐츠리그 대상」, 「제11회 신한 29초영화제 최우수상」, 「The Joyfools - Loser's Love」 같은 고유명사는 검색 가치가 높다.

**두 갈래로 관리**
- **수상작** — 피그마대로 손으로 고정 배치 (가장 중요한 콘텐츠)
- **그 외 수강생 작품** — 유튜브에서 `[FVA 수강생 우수작]` 태그 영상을 자동으로 끌어와 아래에 붙임

각 작품에 **VideoObject 구조화 데이터**를 넣어 검색 결과에 썸네일이 뜨게 한다.

## 7. 외부 연동

### 유튜브 — 자동
- 채널 ID `UCDBwtcf2azG4ghIBqXPnymQ` (@FVA-ACADEMY)
- RSS `https://www.youtube.com/feeds/videos.xml?channel_id=...` — **API 키 불필요, 최신 15개**
- 제목·설명·날짜를 **진짜 텍스트로 렌더링**하고, 썸네일 클릭 시에만 영상을 불러온다 (페이지 무거워지지 않게)
- 제목에 검색어가 이미 풍부함: 영상학원 · 영상연출 · 촬영워크샵 · 셔터스피드 · 3점 조명 · 영상 기획 333법칙

> **임베드 자체는 SEO에 도움이 안 된다.** iframe 내용은 우리 페이지 콘텐츠로 잡히지 않는다. 제목·설명을 텍스트로 뽑아야 의미가 있다.

### 인스타그램 — 수동 (당분간)
- 기본 API가 2024-12 종료. 지금은 비즈니스 계정 + 페이스북 페이지 연동 + 앱 심사 + **60일마다 토큰 갱신**이 필요하고, 놓치면 피드가 멈춘다
- **대표 게시물 몇 개를 고정 배치**하고 캡션은 텍스트로 넣는다
- 신선도는 유튜브 자동 연동이 담당. 나중에 자동화로 올릴 수 있음

## 10. 만드는 순서

1. **메인 페이지** — 피그마 값이 있어 가장 정확하게 나온다. 이거 하나 보고 방향 판단
2. 커리큘럼 → 온라인/오프라인 강의 소개 → 피바뉴스
3. 모바일 대응
4. 유튜브 연동 · 구조화 데이터 · sitemap
5. **도메인 연결 (맨 마지막)** — 그전까지는 미리보기 주소로 확인

도메인을 마지막에 붙이므로 **지금 운영 중인 사이트에는 아무 영향이 없다.** 99% 완성된 걸 보고 전환 여부를 판단한다.
