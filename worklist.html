FVA 정비 체크리스트

사이트·광고·앰버서더를 한 번에 훑고 고친 목록입니다. 남은 일은 맨 아래에 모아뒀습니다.

0 완료 · 0 대기

사이트

  • 퍼블 사이트 간소화겹치던 내용을 정리하고 온라인 강의만 남김
  • 강사 소개 글씨 크기·줄 간격 조정
  • 강사 사진 잘리는 부분 수정
  • 사진 용량 줄이기(이미지 최적화)화질은 그대로
  • 온라인 강의 페이지 설명 보강
  • 오프라인 신청 버튼을 3개월 과정으로 바로 연결전에는 스토어 첫 화면에서 상품을 또 찾아야 했음
  • 검색 결과에 과정·평점·자주 묻는 질문이 함께 뜨도록 정리(구조화 데이터)
  • ChatGPT 같은 AI 검색이 사이트를 읽을 수 있게 허용(AI 크롤러 허용 · llms.txt)
  • 없어진 옛 후기 페이지 주소 정리(리다이렉트)들어오면 새 주소로 넘어가게

측정

  • 방문 분석 설치(GA4)온라인 강의·상담·스토어 버튼을 누른 횟수까지 집계
  • 네이버 방문 분석 설치(네이버 애널리틱스)
  • 인스타 광고 성과 측정 설치(메타 픽셀)만들어만 두고 사이트엔 안 붙어 있었음
  • 구글 광고 성과 측정 설치(구글애즈 전환 태그)
  • 유입 현황 대시보드 제작
  • 대시보드 자동 갱신화면 3분 · 광고 수치 15분
  • 대시보드 주소 정리 · 외부 노출 차단(noindex · robots.txt)광고비와 입찰가가 누구나 볼 수 있는 상태였음

네이버 검색광고

  • 기존 광고 문제 진단「피바아카데미」를 이미 아는 사람만 잡는 검색어 1,000개뿐이었음
  • 실제 검색량을 재서 검색어 17개 선별(키워드)
  • 검색어를 세 갈래로 나눔(광고그룹)기획 · AI영상 · 학원/포트폴리오
  • 갈래마다 광고 문구를 따로 쓰고 도착 페이지도 분리(소재 · 랜딩 페이지)
  • 광고로 들어온 사람을 따로 집계(UTM)네이버는 그냥 두면 검색으로 들어온 것과 구분이 안 됨
  • 어떤 검색어로 들어왔는지까지 수집(네이버 자동추적)
  • 하루 예산 조정 후 광고 시작(일예산)

구글 광고

  • 성과가 0으로 찍히던 원인 진단(전환 추적)「페이지를 열었나」만 보고 있었고 그마저 고장난 상태
  • 엉뚱한 곳에 광고가 나가던 설정 해제(디스플레이 · 검색파트너)
  • 광고에 걸린 죽은 주소 수정(사이트링크)
  • 「상담 버튼 클릭」을 성과로 잡도록 설정(전환 액션)
  • 광고가 그 성과를 보도록 목표 교체(캠페인 전환 목표)

메타 · 인스타 광고

  • 진짜 광고 계정 확인빈 계정을 보고 있었음 · 실제로는 광고 267개가 돌고 있었음
  • 광고마다 비용이 23배까지 벌어진 것 파악잘 되는 건 현장·결과물, 안 되는 건 파티·행사
  • 성과 측정 설치(메타 픽셀)

필름메이커스

  • 광고 문구 작성실제 게시판에서 폭을 재가며 — PC 한 줄, 모바일 두 줄
  • 캐릭터 썸네일 제작배경 네 가지를 실제 화면에 얹어 비교
  • 도착 페이지를 오프라인 강의로 바꾸고 유입 집계 연결(랜딩 URL · UTM)
  • 게시판에 어떻게 보이는지 미리보기 제작
  • 결제 · 집행 접수

앰버서더

  • 후보 모으고 조건으로 걸러내기
  • 25명에게 개인화 DM 발송
  • 3인 확정
  • 계약서 3부 작성사람마다 다른 약속을 조항으로 · 못 지켰을 때 낼 금액도 숫자로
  • 서명본 날짜 처리
  • 카톡방 첫 메시지 · 썸네일 제작
  • 개인 대화방 개설

AI 검색 노출

  • ChatGPT가 사이트를 못 찾던 원인 진단(빙 색인)제미나이는 찾음 — ChatGPT가 쓰는 빙에 사이트가 안 올라가 있었음
  • 빙에 사이트 주소 24개 직접 제출(IndexNow)
