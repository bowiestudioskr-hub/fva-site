# 피바아카데미 공식 홈페이지

퍼블(publ)에서 검색이 안 되는 문제를 풀기 위해 만든 정적 사이트.
결제·회원·강의실·게시판은 퍼블에 그대로 두고, **검색이 필요한 페이지만** 여기서 만든다.

## 실행

```bash
node build.js          # 하위 페이지 + sitemap.xml + robots.txt 생성
open index.html        # 미리보기
```

빌드 도구·의존성 없음. Node만 있으면 된다.

## 구조

```
index.html          메인 — 손으로 정밀 조판 (피그마 실측값)
curriculum.html     커리큘럼 — 손으로 정밀 조판
pages/index.js      온라인·오프라인·작품·뉴스 본문
build.js            헤더·푸터·메타를 씌워 완성 HTML 생성
css/
  style.css         공통 + 메인
  curriculum.css    커리큘럼 전용
  sub.css           하위 페이지 공통
assets/
  img/              히어로·감독·트로피·파트너 + TLAB 제목 PNG
  works/            수강생 수상작 스틸
  video/            쇼릴
```

헤더·푸터·메뉴를 고치려면 `build.js` 만 고치고 `node build.js` 를 돌린다.
단, `index.html` 과 `curriculum.html` 은 빌드 대상이 아니므로 직접 고쳐야 한다.

## 원칙

**글자를 이미지 위에 좌표로 얹지 않는다.**
평면 그래픽(초록 카드·배너)은 CSS로 그리고 그 안에 텍스트를 흘린다.
글자가 길어지면 그릇이 같이 늘어나므로 겹침이 구조적으로 불가능하다.
사진만 이미지로 남기고, 그 위에 글자를 올리지 않는다.

회전시킨 요소는 시각적 박스가 레이아웃 박스보다 커서 가로 스크롤을 만든다.
→ `overflow-x: clip` 으로 감싼다.

## 제목 폰트

큰 제목은 **TLAB 믹스커피**(유료)라 웹에 못 싣는다.
피그마에서 투명 PNG로 뽑아 `<h2><img alt="실제 문구"></h2>` 형태로 넣었다.
검색엔진은 alt를 제목 텍스트로 읽으므로 손해가 없다.
폰트를 구매하면 img를 텍스트로 바꾸기만 하면 된다.

## 도메인 붙일 때

1. `build.js` 의 `PUBL` 을 `https://class.fva.co.kr/...` 로 교체
2. 퍼블 채널 도메인을 `class.fva.co.kr` 로 변경
3. 가비아에서 `fva.co.kr` 네임서버를 이 사이트 호스팅으로 변경

## 검증

`node build.js` 후 320~1920px 각 폭에서 가로 스크롤 0px, 텍스트 밀림 0px,
깨진 이미지 0개를 확인했다.
